# 方法选择：缺陷类型 → 方法 → 验收

先按分流顺序定路线，再查表挑具体方法。配方名和参数以 `recipes/CATALOG.md` 为准，CATALOG 标「未验证」的配方先在副本上试；写 `MCP xxx` 的是 Higgsfield MCP 的 `ps_do` 操作。案例编号 K1–K7 见 [known-failures.md](known-failures.md)。

## 分流顺序（每处缺陷单独判断）

1. **用户点名了方法就用那个。** 指定生成式填充就不拿内容识别顶替，报告里照实写用了哪个。
2. **缺陷是前面某一步修出来的**（蒙版漏了、滤镜盖到别处、调整层没剪贴）：回到那一层改，不叠新方法。
3. **材质和结构都在，只是颜色、明暗、清晰度不对**：调整层或滤镜副本加蒙版。
4. **小块，四周有同材质能接续**：无结构背景用内容识别填充，有结构线用邻近贴片，都不行再用生成式填充。
5. **大块，或要凭空补出结构**（跨几种材质、要重建瓦、檐、窗）：回即梦局部重绘，PS 只做合回和调色。看的是要补出多少原本不存在的结构，不只看面积；一小块但结构全乱的也归这条。
6. **透视、机位、整体比例错**：回生成端重出，PS 里不修，写进报告。

同一方法两次不过就换下一条路线。加大羽化、加模糊、降不透明度修不了错位和结构，只会把问题变糊。

## 内容识别填充

秒级、不扣积分，在复制层上做，开颜色适应。选区外扩几像素包住物件的边和影子（`grow_px`），蒙版再大几像素（`expand_px`），羽化一两像素（`feather_px`）。源图层是背景层时，改动只落在返回的 `fill_bounds` 里，验收的修改框就取它。适合天空、雾、雪地这类无结构背景；木板、砖、瓦这类带结构线的材质上会留浅色涂抹，线条接不上（K3）。

## 生成式填充

- 用前告诉用户：每次扣 Adobe 生成积分，要 2–4 分钟（实测 106 秒、229 秒），同意再跑。
- 直接在工作文档上跑一次，不建副本、不拷回。`generative_fill` 把 `layer_id`（缺省背景层）复制成「修_genfill_src」，在它上面生成「修_generative_fill_<label>」（带蒙版的智能对象），随后把「修_genfill_src」隐藏；背景层不动。「修_genfill_src」留在源图层正上方（隐藏）；产出层默认移到最顶层（`to_top`），不会被之前的修复层挡住，要它留在原位就传 `to_top:false`。
- 先用 `dry_run:true` 核对选区和参数，不扣积分。
- 选区贴着缺陷，外扩够过渡即可，不框大矩形。空提示词优先；要写就只写这处应是什么材质。
- 产出层边界比选区四边各外扩约 11 px；算区外 PSNR 的修改框取返回的产出层 bounds 再加几像素，只按选区算不是 inf（K4）。
- 看结果：物件没了只是第一项，还要看有没有新长出的划痕、零件，结构走向有没有变（K4 复跑就多长出一道门槛状横条）。不满意就用 `layer_ops` 隐藏或删掉「修_generative_fill_<label>」；再试一次先告诉用户会再扣一次积分，两次不行换路线。
- 超时：给 `--timeout 900`。AppleScript 等到 2 分钟会报超时，psrun 接着轮询结果文件，PS 里照样跑完；返回 `TIMEOUT` 先 `inspect` 查图层，不重跑，否则再扣一次积分、叠出第二层（K6）。

## 即梦局部重绘合回

1. **导出局部。** 用验收那条导出路径导出当前合成全图（含已做的修复，不用桌面上的旧原图），再用 ffmpeg `crop=宽:高:x:y` 裁出缺陷外扩约一倍的范围，给即梦留出对光线和透视的上下文。记下左上角 `x0,y0` 和宽高。
2. **即梦重绘。** 由用户在即梦里操作（涉及账号和积分）。执行者给出：局部图路径、要涂抹的范围、一句重绘提示词——写这里应该是什么（材质、结构走向、受光），不写「去掉」「修复」，机位和光线保持原样。请用户下载原图，不用截图。
3. **核对返回图。** 宽高比应和局部图一致：只是放大了就等比缩回局部图尺寸；比例不同说明被裁或补了边，问清再用。重绘块本身结构不对就再重绘，不靠蒙版遮。
4. **放回。** `place_image` 直接给 `x`、`y`（局部图左上角 `x0,y0`）；返回图只是等比放大时再给 `width`、`height`（只给一个按比例缩），不给就是 1:1 原尺寸。返回的 `corners` 应正好是 `x0,y0` 到右下角。MCP `document.place` 落在画布中心，要 `layer.info` 读边界再 `layer.translate`。放好后用三个以上地标（梁角、石缝、窗框）核对，差一像素也要调。
5. **蒙版。** 只露出修复范围外扩几像素，羽化按边缘软硬：`place_image` 带 `selection`（修复范围）、`expand_px`、`feather_px` 一步建好，不带就是全显蒙版，事后用 `mask_from_selection`（`replace:true`）重建。即梦常顺带改动局部图的其他地方，蒙版外的改动一律不露。
6. **匹配颜色。** 用剪贴到该层的曲线、色彩平衡把明暗和色调调到接缝两侧看不出差；颗粒不同加极弱单色杂色。
7. **验收。** 修改框取局部图范围，区外 PSNR=inf；接缝放大、暗部提亮各看一遍。

## 通用做法

- 调整层要加蒙版或剪贴到补丁层；全图生效会让区外 PSNR 不是 inf。
- 去掉物体时连它的影子、倒影、光晕一起去；保留下来的光源照出的光要留着。
- 羽化宽度照边缘本来的软硬：建筑硬边一两像素，雾、烟、远景才用大羽化。大羽化盖不住错位。
- 同一层先做像素滤镜、后建蒙版；层上已有蒙版时，有的滤镜会作用到蒙版上，把改动带出边界。配方已按这个顺序做，这条管的是 MCP 滤镜。
- 像素类滤镜和 `camera_raw` 只在选区外接框加余量的矩形里计算，框外靠蒙版挡住。去朦胧、清晰度这类看全局的调整，局部算和整图算略有差别；要整图效果就不给选区。
- 自动化时每条配方显式传 `doc_id`、`layer_id`：像素类的 `layer_id` 是源图层（一般是背景层），调整类的 `layer_id` 是新层插在哪层上方。
- MCP 复制出的层（如邻近贴片）先用 `layer.rename` 改成「修_贴片_<标签>」：`mask_from_selection`、`mask_set`、`layer_ops` 只改「修_」开头的层。
- 修好一处就在全图找同类缺陷，列进缺陷表，修不修由用户定。
- 深读：分流逻辑读 ps-deslop 的 `method-selection.md`，各类材质的毛病分法读 `surface-completion.md`，树、地形、水读 `nature.md`（运行时用 `ps_get_skill` 读）。
